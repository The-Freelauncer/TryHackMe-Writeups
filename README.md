# TryHackMe Writeups 🛡️

A comprehensive collection of my walkthroughs, security notes, and exploitation steps for rooms completed on [TryHackMe](https://tryhackme.com). 

## 📂 Repository Structure

Writeups are organized by room difficulty and category to make finding specific challenges straightforward:

* **[Beginner / Introductory Paths](#)** - Basic security concepts, pre-security, and foundational tool usage.
* **[Easy / Medium Rooms](#)** - Standard CTF-style challenges, common web vulnerabilities (OWASP Top 10), and basic enumeration.
* **[Hard / Insane Rooms](#)** - Advanced pivoting, complex privilege escalation vectors, and custom exploitation.
* **[Path-Specific Modules](#)** - Complete walkthroughs for structured learning paths (e.g., Jr. Penetration Tester, Cyber Defense, Offensive Pentesting).

---

## 🛠️ Typical Workflow & Methodology

Every writeup generally follows a structured penetration testing methodology:
1. **Reconnaissance & Enumeration:** Nmap scans, directory busting (Gobuster/Feroxbuster), service version checking.
2. **Vulnerability Assessment:** Analyzing findings, researching CVEs, and identifying misconfigurations.
3. **Exploitation:** Gaining an initial foothold via uploaded shells, default credentials, or exploit scripts.
4. **Privilege Escalation:** Enumerating local system permissions (Sudo rights, SUID binaries, kernel exploits) to achieve `root` or `Administrator`.
